# S4 验证与小规模试错实验

目的：把"我觉得"变成"测过，效应量是多少"。

## 1. 预注册（先写后跑）

每个实验 `add experiment`，必须在任何结果出现前写好：

- `hypothesis_id`、可选 `crux_id`
- `method`：做什么（回测 / Fermi / 蒙特卡洛 / 复现 / 代码实验 / 专家问题）
- `metric` 与 `threshold`：用什么量、过线标准
- `prediction`：假设为真时预期值
- `decision_rule`：结果落在哪里时假设升级/降级/推翻
- `budget`：时间、算力、token 上限

事后想改阈值 = 新实验（新 E#），旧实验与结果保留。

## 2. 实验菜单（由便宜到贵）

| 方法 | 适用 | 交付 |
| --- | --- | --- |
| 历史回测 | 假设能对过去做预测 | 预测 vs 实际，误差 |
| Fermi + 敏感性 | 成本、规模、时间类假设 | 区间与最敏感因素 |
| 蒙特卡洛 / 情景 | 多个不确定因素叠加 | P5/P50/P95，过线概率 |
| 复现关键数字 | 结论依赖某篇论文/报告的数字 | 能否复现，偏差多少 |
| 小代码实验 / 仿真 / 基准测试 | 算法、软件、可模拟的物理过程 | 指标、对照组、重复次数 |
| 数据切片 | 有公开数据集 | 分组对比、效应量、置信区间 |
| 专家问题 | 只有业内人知道 | 3 个能判决 crux 的问题，交给用户去问 |

所有脚本放 `experiments/E{n}_*.py`，固定随机种子，能一条命令重跑。

## 3. 剖析 = 消融

对主假设（以及每个 crux 涉及的模型）跑：

```bash
python3 scripts/ablate.py --model experiments/model.py --params experiments/params.json --out experiments/ablation
```

- **消融价值**：把一个因素拿掉（置为"不贡献"状态）后结果变多少，回答"这个因素值多少"。
- **龙卷风**：其他因素不动，单因素在低/高之间摆动的幅度，回答"哪个最敏感"。
- **蒙特卡洛**：全部不确定性叠加后的分布。
- **方差贡献**：结果的不确定性主要来自谁，决定 S5 优先把钱花在哪个因素上。
- **交互项**：两个因素不能分开算时会显示。

参数区间来自台账（`src` 字段写 K#/S#）。这个实验登记为 `ablation: true`。

## 4. 记录结果

`add result`：`observed`、`passed`、`effect`（效应量或差值，带单位）、`confidence`、`hypothesis_state`（supported / weakened / refuted / inconclusive）、`surprise`（意外发现，常常是下一轮循环的起点）。

失败与不显著的实验同样记录。被推翻的假设不删，留在记分卡上。
