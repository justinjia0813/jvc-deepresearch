# S2 第一性原理

第一性原理不是口号，是一套可以检查的动作：把结论拆到**不依赖类比的不变量**，再用**历史基准率**校正乐观。

## 1. 拆解

对研究问题画一棵"结论依赖树"：根是结论，叶子是不能再拆的量。每个叶子归到一类：

| 类 | 例子 | 记录 |
| --- | --- | --- |
| 物理/化学极限 | 理论比容量、卡诺效率、香农极限、光刻衍射极限 | `constraint`，写公式和数值 |
| 守恒与量纲 | 能量/质量平衡、单位换算是否闭合 | `constraint` |
| 成本地板 | 原材料成本 × 用量、能耗 × 电价、折旧 | `constraint`，带来源 |
| 恒等式 | 收入 = 量 × 价；毛利 = 价 − 单位成本；资本回收 | `constraint` |
| 经验规律 | 学习曲线（每翻倍降 x%）、规模律、良率爬坡 | `baserate` 或 `constraint`，注明是经验不是定律 |

规则：每个数值有单位和来源或推导；不确定的给区间（low/base/high），这些区间直接喂给 S4 的 `ablate.py`。

## 2. 参考类与基准率

问"同类事情过去 50–100 年通常怎么发展"：

- 选 2–3 个参考类（宽一个、窄一个），例如"新电池化学体系从论文到 1 GWh 量产""新半导体材料从发现到主流制程"。
- 记录基准率：成功比例、平均耗时、成本下降速度、最常见死因。`add baserate`，`n` 写样本数。
- 当前案例与参考类的差异要逐条写出，每条差异要有证据才能调整基准率。

## 3. "必须为真"清单

结论要成立，哪 3–7 件事必须同时为真？对每件：当前证据强度（强/中/弱/无）、最便宜的验证方式。联合概率 ≈ 各项概率之积，这往往是纠正乐观最有效的一步。

## 4. 形成假设

3–8 条，每条可证伪：

- `text`：一句话主张；
- `prediction`：如果为真，可以观察到什么（带数）；
- `falsifier`：什么结果算推翻；
- `metric`：S4 用什么指标检验。

至少一条 `contrarian: true`（主流叙事是错的）。用户带倾向时，至少一条与该倾向相反。
